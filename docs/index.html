Helm chart repository for BandwidthOnDemand/nsi-node

Frozen on 2026-08-20 — no new chart versions will be published here

Charts are now published as OCI artifacts by each source repository, on every release tag. The chart version equals the application version equals the git tag. 

        oci://ghcr.io/workfloworchestrator/charts   ana-automation-ui, nsi-aggregator-proxy,
                                                   nsi-aura, nsi-auth, nsi-dds-proxy,
                                                   nsi-mgmt-info, nsi-orchestrator,
                                                   nsi-orchestrator-ui, polynsi, supa
        oci://ghcr.io/bandwidthondemand/charts     nsi-dds, nsi-pce, nsi-safnari

No helm repo add is needed. Reference a chart directly: 

        helm show chart oci://ghcr.io/workfloworchestrator/charts/nsi-orchestrator --version <version>
        helm upgrade --install nsi-orchestrator \
            oci://ghcr.io/workfloworchestrator/charts/nsi-orchestrator --version <version>

In a Chart.yaml dependency, the repository is the namespace without the chart name; the "@nsi-node" alias form does not work for OCI: 

        dependencies:
          - name: nsi-dds
            version: "<version>"
            repository: "oci://ghcr.io/bandwidthondemand/charts"

This index and its .tgz files are kept online indefinitely so existing pinned versions keep resolving. Everything served from here is the state as of the freeze date above; anything released later exists only in the registries listed above. 

        helm repo add nsi-node https://bandwidthondemand.github.io/nsi-node/
        helm repo update
